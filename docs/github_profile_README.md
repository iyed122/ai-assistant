## 🚀 Projects

### [AI Assistant — Graph-RAG & Self-Improving Evaluation](https://github.com/iyed122/ai-assistant)
A fully local enterprise assistant over a **Neo4j knowledge graph** (~1.28 M document chunks). It combines hybrid **Graph-RAG** retrieval, a concurrent **LangGraph** agent, and a self-evaluating **"Hammer"** loop that scores every answer and feeds a gated **QLoRA / DPO** fine-tuning pipeline. Runs 100 % on-premise on a single 6 GB GPU.

`Python` · `LangGraph` · `Neo4j` · `Ollama` · `RAGAS` · `QLoRA/DPO` · `MLflow` · `Docker`

### [Autonomous Vehicle — Vision-Language Model](https://github.com/iyed122/autonomous-vehicule-VLM)
A self-driving prototype that uses a **Vision-Language Model** to interpret the road scene from camera input and produce driving decisions — bridging perception and reasoning in a single model.

`Python` · `PyTorch` · `Vision-Language Models` · `Computer Vision`

### [Automated Twitter Content](https://github.com/iyed122/automated-twitter-content)
An **LLM-powered content pipeline** that turns a topic or brief into ready-to-post X / Twitter content, automating generation, formatting and scheduling end to end.

`Python` · `LLMs` · `Automation` · `REST APIs`
